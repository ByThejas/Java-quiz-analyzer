# 🧠 Java Quiz Analyzer

A simple console-based quiz application built with Java to practice core Java concepts, especially arrays, loops, conditions, and user input.

## 📌 About

This project is a 5-question Java quiz where the user answers each question through the console.

The program stores the questions, correct answers, and user answers using arrays, then analyzes the results and displays the final score.

## ✨ Features

- 🧠 5-question Java quiz
- ⌨️ Takes answers through `Scanner`
- 📦 Stores questions using arrays
- ✅ Stores correct answers
- 👤 Stores user answers
- 📊 Calculates the final score
- ❌ Counts incorrect answers
- 📈 Calculates percentage
- 🔍 Shows which questions were correct or incorrect
- 💡 Displays the correct answer when the user gets a question wrong

## 🧠 Java Concepts Practiced

- Variables and data types
- `String` arrays
- `int` arrays
- Array indexing
- `.length`
- `for` loops
- `if-else` statements
- `Scanner`
- Type casting
- Counters
- Comparing multiple arrays using the same index
